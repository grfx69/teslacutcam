Export video

Tesla clips carry no gyroscope data (only speed, pedals, steering, GPS and acceleration), so stabilization is video-based: camera shake is measured from the image and cancelled by a small crop + shift. Rotation is not corrected.

These settings only affect the exported file; the live view keeps its own overlay toggles.

Performance

Long exports are processed in chunks and written into one MP4 file; this only changes chunk size and memory use.

Map

Map tiles load from Esri / CARTO (OpenStreetMap) over the internet; only tile coordinates are requested, never your video. Offline, the map shows the path and street only.

Street names (optional)

To enable: get a free key at https://locationiq.com, paste it (just the key) into a file named teslacam-geo.key next to Start Tesla Cut Cam Export.bat, then restart it. The key stays on your PC; the page only talks to the helper on the same address. On the website version the server operator provides this. Without it, the app shows the street/city from event.json, or GPS coordinates.
